# Pop-Art Arcade UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đổi toàn bộ giao diện frontend sang phong cách Anime Pop-Art / Japanese Arcade theo spec `docs/superpowers/specs/2026-10-17-pop-art-ui-design.md`, không đổi luồng chơi, nội dung chữ hay hành vi.

**Architecture:** Token màu, font, animation khai báo trong `@theme` của Tailwind v4; vài utility riêng (`clip-slant`, `drop-hard`, `hard-*`, `halftone`, `halftone-strong`, `disc-face`) viết bằng `@utility` trong `src/index.css`. Thêm component dùng chung (`PopButton`, `PopLink`, `PopPanel`, `PopChip`, `Callout`, `CdDisc`, `Burst`) rồi đổi từng trang sang dùng chúng. Mọi chuỗi class viết nguyên văn để Tailwind quét thấy.

**Tech Stack:** Vite 8, React 19, TypeScript 6, Tailwind CSS 4.3 (`@tailwindcss/vite`), Vitest + Testing Library, oxlint, Playwright, `@fontsource/barlow-condensed` 5.x.

## Global Constraints

- Màu: `--color-pop-ink: #0b0b0b`, `--color-pop-paper: #fbfbf4`, `--color-pop-red: #e8112d`, `--color-pop-lime: #e4ff1a`. Không dùng `slate-*`, `sky`, `emerald`, `amber`, `blue`, `green` trong UI; chữ phụ `text-neutral-400`, nền phụ `bg-neutral-900`/`bg-neutral-800`.
- Font: `'Barlow Condensed', system-ui, sans-serif`, chỉ các độ đậm đã tải: `font-medium` (500), `font-semibold` (600), `italic font-extrabold` (800), `italic font-black` (900). Không dùng `font-bold`. Không dùng `italic` mà thiếu `font-extrabold`/`font-black`. `font-mono` đổi thành `tabular-nums`.
- Chữ in hoa chỉ bằng CSS `uppercase`; nội dung chữ trong JSX giữ nguyên.
- Giữ nguyên mọi nội dung chữ, `role`, `aria-label`, `data-testid`, `data-state`, `data-layout`, `data-me`, `data-online`, `title` mà test đang dùng.
- Không tải gì từ `fonts.googleapis.com`.
- Mọi animation, phóng to, xoay đặt sau `motion-safe:`; nốt nhạc và tia chớp có thêm `motion-reduce:hidden`. Đổi màu khi hover/chạm không cần `motion-safe:`.
- Hover chỉ áp dụng cho phần tử bấm được và đang bật (`enabled:`/`not-disabled:`); điện thoại dùng `active:`.
- Viền đi theo cạnh vát: 2 lớp `clip-slant` lồng nhau (lớp ngoài màu viền + `p-[2px]`/`p-[3px]`). Bóng cứng `drop-hard` đặt trên phần tử bọc ngoài lớp có `clip-slant`.
- Mỗi file chỉ export component (rule oxlint `react/only-export-components`); hàm/hằng không phải component để ở file `.ts` riêng.
- Lệnh kiểm tra (chạy trong `frontend/`): `npm test && npx tsc -b && npm run lint`; cuối cùng `npm run e2e` rồi `npm run build`.
- Commit trên nhánh `pop-art-ui`; mỗi commit kết thúc bằng dòng `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Chỗ lệch nhỏ so với spec (đã cập nhật vào spec trong cùng commit với kế hoạch)

1. `STAGE_CLASSES` không dùng `translate` để đặt giữa. Theo CSS Transforms, phần tử con của một phần tử có `transform` coi `background-attachment: fixed` như `scroll`, nên lớp phủ `halftone-strong` sẽ không trùng nền. Thay bằng `left-[calc(50%-160px)] top-[calc(50%-90px)]`; layout `large` dùng `h-[31.5vw]` thay `aspect-video` để chiều cao chuyển động mượt.
2. `popButtonClasses` nằm ở `components/popButtonClasses.ts` (rule oxlint ở trên) và trả về `{ outer, frame, face }` (3 lớp vì biến thể `secondary` cần lớp viền theo cạnh vát).
3. Keyframes `bolt-flash` viết lại để tia chớp tắt hẳn sau mốc 14% (bản mẫu với `steps(1)` giữ `opacity: 1` từ 14% tới 100%).
4. Thêm component `Burst` (hình nổ 12 cánh) dùng chung cho màn đo độ trễ và băng "Đúng!".

```css
@theme {
  --color-pop-ink: #0b0b0b;

  --color-pop-lime: #e4ff1a;

  --animate-note-fly: note-fly 2.2s ease-out infinite;

  --animate-slam: slam 0.35s cubic-bezier(0.2, 1.6, 0.4, 1) both;

    to {
      transform: rotate(360deg);
    }
  }

      opacity: 0;
    }
    15% {
      opacity: 1;
    }
    100% {
      transform: translate(calc(-50% + var(--dx)), calc(-50% + var(--dy))) scale(1.3) rotate(var(--rot));
      opacity: 0;
    }
  }

  @keyframes bolt-flash {
    0%,
    14%,

    }
    8%,
    12% {
      opacity: 1;
    }
    10% {
      opacity: 0.2;
    }
  }

    from {
      transform: scale(1.4) rotate(-4deg);
      opacity: 0;
    }

      transform: scale(1) rotate(0);
      opacity: 1;
    }
  }
```

```ts
export type PopVariant = 'primary' | 'secondary' | 'danger'
export type PopSize = 'sm' | 'md' | 'lg'

export interface PopButtonLook {
  outer: string
  frame: string
  face: string
}

// Chuỗi class viết nguyên văn để Tailwind quét thấy. not-disabled: khớp cả <a> và <label>.
const MOTION =
  'motion-safe:transition-transform motion-safe:duration-150 motion-safe:not-disabled:hover:scale-[1.07] motion-safe:not-disabled:hover:-rotate-[1.5deg] motion-safe:not-disabled:active:scale-[1.07] motion-safe:not-disabled:active:-rotate-[1.5deg]'

const SHADOW: Record<PopVariant, string> = {
  primary: 'hard-pop-red',
  secondary: 'hard-pop-red',
  danger: 'hard-pop-paper',
}

// Lớp khung mang màu viền theo cạnh vát; chỉ nút secondary có viền.
const FRAME: Record<PopVariant, string> = {
  primary: '',
  secondary: 'bg-pop-paper p-[2px]',
  danger: '',
}

const FACE: Record<PopVariant, string> = {
  primary:
    'bg-pop-lime text-pop-ink group-not-disabled:group-hover:bg-pop-red group-not-disabled:group-hover:text-pop-paper group-not-disabled:group-active:bg-pop-red group-not-disabled:group-active:text-pop-paper',
  secondary:
    'bg-pop-ink text-pop-paper group-not-disabled:group-hover:bg-pop-paper group-not-disabled:group-hover:text-pop-ink group-not-disabled:group-active:bg-pop-paper group-not-disabled:group-active:text-pop-ink',
  danger:
    'bg-pop-red text-pop-paper group-not-disabled:group-hover:bg-pop-paper group-not-disabled:group-hover:text-pop-red group-not-disabled:group-active:bg-pop-paper group-not-disabled:group-active:text-pop-red',
}

const SIZE: Record<PopSize, { slant: string; face: string }> = {
  sm: { slant: '[--slant:8px]', face: 'px-3 py-1 text-base' },
  md: { slant: '[--slant:12px]', face: 'px-5 py-2 text-xl' },
  lg: { slant: '[--slant:14px]', face: 'px-8 py-3 text-3xl' },
}

export function popButtonClasses(variant: PopVariant, size: PopSize): PopButtonLook {
  return {
    outer: `group inline-flex drop-hard ${SHADOW[variant]} ${SIZE[size].slant} ${MOTION} disabled:cursor-not-allowed disabled:opacity-40`,
    frame: `flex flex-1 clip-slant ${FRAME[variant]}`,
    face: `flex-1 clip-slant text-center leading-tight font-black uppercase italic transition-colors duration-150 ${SIZE[size].face} ${FACE[variant]}`,
  }
}
```

- [ ] **Step 4: Viết `src/components/PopButton.tsx`**

```tsx
import type { ButtonHTMLAttributes } from 'react'
import { Link, type LinkProps } from 'react-router'
import { popButtonClasses, type PopSize, type PopVariant } from './popButtonClasses'

interface Look {
  variant?: PopVariant
  size?: PopSize
}

export function PopButton({
  variant = 'primary',
  size = 'md',
  type = 'button',
  className = '',
  children,
  ...rest
}: ButtonHTMLAttributes<HTMLButtonElement> & Look) {
  const look = popButtonClasses(variant, size)
  return (
    <button type={type} className={`${look.outer} ${className}`} {...rest}>
      <span className={look.frame}>
        <span className={look.face}>{children}</span>
      </span>
    </button>
  )
}

export function PopLink({ variant = 'primary', size = 'md', className = '', children, ...rest }: LinkProps & Look) {
  const look = popButtonClasses(variant, size)
  return (
    <Link className={`${look.outer} ${className}`} {...rest}>
      <span className={look.frame}>
        <span className={look.face}>{children}</span>
      </span>
    </Link>
  )
}
```

```tsx
import type { ReactNode } from 'react'

type ChipTone = 'paper' | 'red' | 'lime'

const CHIP_TONES: Record<ChipTone, string> = {
  paper: 'bg-pop-paper text-pop-ink shadow-[5px_5px_0_var(--color-pop-red)]',
  red: 'bg-pop-red text-pop-paper shadow-[5px_5px_0_var(--color-pop-ink)]',
  lime: 'bg-pop-lime text-pop-ink shadow-[5px_5px_0_var(--color-pop-red)]',
}

interface ChipProps {
  as?: 'h1' | 'h2' | 'p' | 'span'
  tone?: ChipTone
  className?: string
  children: ReactNode
}

// Hình bình hành nhờ skew (không dùng clip-path) nên đổ bóng trực tiếp bằng box-shadow.
export function PopChip({ as: Tag = 'span', tone = 'paper', className = '', children }: ChipProps) {
  return (
    <Tag
      className={`inline-block w-fit -skew-x-12 -rotate-2 px-3 py-1 leading-none font-black uppercase italic ${CHIP_TONES[tone]} ${className}`}
    >
      {children}
    </Tag>
  )
}

interface PanelProps {
  title?: string
  titleAs?: 'h1' | 'h2'
  className?: string
  children: ReactNode
}

export function PopPanel({ title, titleAs = 'h2', className = '', children }: PanelProps) {
  return (
    <section className={`drop-hard hard-pop-red ${className}`}>
      <div className="clip-slant bg-pop-paper p-[3px] [--slant:18px]">
        <div className="clip-slant flex flex-col gap-4 bg-neutral-950 p-6 [--slant:18px]">

              {title}
            </PopChip>
          )}
          {children}
        </div>
      </div>
    </section>
  )
}
```

```tsx
  return `${(50 + radius * Math.cos(angle)).toFixed(1)},${(50 + radius * Math.sin(angle)).toFixed(1)}`
}).join(' ')

export function Burst({ className = '' }: { className?: string }) {
  return (
    <svg viewBox="0 0 100 100" aria-hidden="true" className={className}>
      <polygon points={POINTS} />
    </svg>
  )
}
```

```tsx
import { TILES, type TileState } from './tiles'

interface Props {
  index: number
  label: string
  state?: TileState
  count?: number
  disabled?: boolean
  layout?: 'row' | 'stack'
  onSelect?: (index: number) => void
}

const HOVER_MOTION =
  'motion-safe:enabled:hover:scale-[1.07] motion-safe:enabled:hover:-rotate-[1.5deg] motion-safe:enabled:active:scale-[1.07] motion-safe:enabled:active:-rotate-[1.5deg] disabled:cursor-not-allowed'

const STATE_MOTION: Record<TileState, string> = {
  idle: '',
  chosen: 'motion-safe:scale-[1.04] motion-safe:-rotate-[1.5deg]',
  correct: 'motion-safe:scale-[1.05]',
  wrong: '',
  dimmed: '',
}

// Cấu trúc: phần tử ngoài (bóng cứng, phóng to) > lớp viền clip-slant > mặt clip-slant.
// Ô chỉ phản ứng với chuột khi là button đang bật: chuột của quản trò dừng trên ô nào thì cả stream thấy.
export function AnswerTile({ index, label, state = 'idle', count, disabled, layout = 'row', onSelect }: Props) {
  const tile = TILES[index]
  const interactive = onSelect !== undefined
  const chosen = state === 'chosen'
  // Mờ trên lớp viền: drop-hard đã chiếm thuộc tính filter của phần tử ngoài.
  const faded = state === 'dimmed' || state === 'wrong'

  const outer = `group relative flex w-full text-left drop-hard motion-safe:transition-transform motion-safe:duration-150 ${
    chosen ? tile.hardSwap : tile.hard
  } ${STATE_MOTION[state]} ${interactive ? `${tile.hardHover} ${HOVER_MOTION}` : ''}`
  const frame = `flex flex-1 clip-slant p-[3px] ${tile.border} ${faded ? 'opacity-30 grayscale' : ''}`
  const face = `flex min-w-0 flex-1 clip-slant transition-colors duration-150 ${chosen ? tile.swap : tile.face} ${
    interactive ? tile.faceHover : ''
  } ${layout === 'stack' ? 'flex-col justify-between gap-2 px-5 py-3' : 'items-center gap-3 py-3 pr-7 pl-6'}`

  const letter = (
    <span aria-hidden="true" className="text-[1.8em] leading-none font-black italic">
      {tile.letter}
    </span>
  )
  const symbol = (
    <span aria-hidden="true" className="text-[0.7em]">
      {tile.symbol}
    </span>
  )
  const name = <span className="min-w-0 leading-tight font-extrabold break-words italic">{label}</span>

  const body = (
    <>
      <span className={frame}>
        {layout === 'stack' ? (
          <span className={face}>
            {letter}
            <span className="flex items-baseline gap-1.5">
              {symbol}
              {name}
            </span>
          </span>
        ) : (
          <span className={face}>
            {letter}
            {symbol}
            <span className="flex min-w-0 flex-1">{name}</span>
            {count !== undefined && (
              <span className="-skew-x-12 bg-pop-ink px-3 py-1 font-black text-pop-lime italic tabular-nums">
                {count}
              </span>
            )}
          </span>
        )}
      </span>
      {state === 'correct' && (
        <span
          aria-hidden="true"
          className="absolute -top-3 -right-2 rotate-8 bg-pop-paper px-2 py-0.5 text-base font-black text-pop-red uppercase italic shadow-[3px_3px_0_var(--color-pop-ink)]"
        >
          ✓ Đúng
        </span>
      )}
      {state === 'wrong' && (
        <span
          aria-hidden="true"
          className="absolute -top-3 -right-2 rotate-8 bg-pop-red px-2 py-0.5 text-xl leading-none font-black text-pop-paper italic shadow-[3px_3px_0_var(--color-pop-ink)]"
        >
          ✕
        </span>
      )}
    </>
  )

  if (!interactive) {
    return (
      <div className={outer} data-state={state}>
        {body}
      </div>
    )
  }
  return (
    <button
      type="button"
      className={outer}
      data-state={state}
      aria-label={`${tile.letter}: ${label}`}
      disabled={disabled}
      onClick={() => onSelect(index)}
    >
      {body}
    </button>
  )
}
```

```tsx
interface Props {

const RADIUS = 46
const CIRCUMFERENCE = 2 * Math.PI * RADIUS
const URGENT_SECONDS = 5

// Nốt nhạc bay từ tâm ra quá mép đĩa; cqw tính theo bề rộng đĩa (gốc là @container).

  { glyph: '♩', dx: '6cqw', dy: '-62cqw', rot: '10deg', delay: '0.8s', color: 'text-pop-paper' },

export function CdDisc({ remainingMs, totalMs = 0, size, spin = true, className = '' }: Props) {
  const timed = remainingMs !== undefined
  const seconds = timed ? Math.ceil(remainingMs / 1000) : 0
  const fraction = timed && totalMs > 0 ? Math.min(1, Math.max(0, remainingMs / totalMs)) : 0

  return (

            cy="50"

            strokeWidth="6"

            strokeDashoffset={CIRCUMFERENCE * (1 - fraction)}
```

```tsx
          </p>
```
```tsx
          {errorBox}
          {replayButton('md')}
        </div>
      </div>
```
